# 0008 — Hand-rolled Markdown, validation and icons instead of dependencies

**Status:** accepted · **Date:** 2026-10-17 · **Context:** V0.1


Each candidate dependency (marked/dompurify, zod, an icon set, sharp) would add
bundle weight or native build risk for a small, well-understood problem.

**Decision:** write an escape-first Markdown renderer with an allowlisted URL
scheme; explicit repair-oriented validators; SVG icons as one component; PNG
icons generated by a dependency-free script.

**Consequences:** small bundle, no native modules, security rules visible in
one file; the cost is maintenance we accept and test.
