# 0004 — Evidence ladder that never auto-advances

**Status:** accepted · **Date:** 2026-10-17 · **Context:** V0.1


A journal that upgrades its own claims becomes fiction.

**Decision:** evidence levels concept→…→deployed advance only by explicit user
action; `verified`/`deployed` require at least one evidence reference
(enforced in validation and import); hedged language demotes; milestones start
as `claimed`.

**Consequences:** exports and timelines can be trusted as a record of what was
known when.
