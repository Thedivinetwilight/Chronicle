# Chronicle

A quiet, offline-first record of your projects, experiments, decisions and days.

Chronicle is a **local-first** app: everything you write lives in your browser's
IndexedDB, works without a network, and leaves your device only when you
explicitly export it or opt in to AI assistance. There is no account, no
server, no telemetry.

V0.1 is implemented and runnable — see [docs/ROADMAP.md](docs/ROADMAP.md) for
what is deliberately not here yet.

## What it does

- **Capture** — write one plain sentence ("Fixed the retrieval bug in JARVIS
  yesterday; need to re-run the benchmark tomorrow") and Chronicle derives a
  journal entry, links the project, extracts tasks with their own due dates,
  and proposes milestones. Nothing is invented: anything uncertain is shown
  for review, and your original words are always preserved verbatim.
- **Journal** — entries with type, tags, evidence level, privacy and a full
  edit history you can restore.
- **Projects** — containers with status, an evidence stage, aliases and
  safe deletion (archive + unlink by default; nothing is ever hard-deleted by
  accident).
- **Timeline** — everything that happened, in order, grouped by your local day.
- **Search** — local full-text search over titles, bodies, tags and original
  capture text, with `#tag` filters and highlighted matches.
- **Portability** — versioned JSON archives with checksums, Markdown export,
  and an import flow that previews changes and never silently overwrites
  newer local records.
- **Installable** — a PWA with offline support; add it to your home screen on
  Android or install it from the browser on desktop.

## Run it

```bash
npm install
npm run dev        # local development server
npm run verify     # typecheck + tests + contrast + production build
npm run preview    # serve the production build
```

Scripts: `npm test` (Vitest, jsdom + fake-indexeddb), `npm run icons`
(regenerates PWA icons without native deps), `npm run contrast` (WCAG check of
the design tokens).

## Principles

1. **Your data stays yours.** Local storage first; export/import is a
   first-class feature, not an afterthought.
2. **Honesty over polish.** Chronicle never claims work is verified, never
   back-dates anything, and tells you when it is unsure instead of guessing
   silently.
3. **Restraint.** One accent colour, real type scale, no dashboards, no fake
   metrics. The interface exists to get out of the way of your record.
4. **Reversibility.** Deletes are tombstones you can restore; edits keep
   snapshots; imports can be previewed and refused.
